## Process metrics (not outcome fails)

Expected eligibility: applicability task path under `repo/src/notifications/legacy` is `not-applicable` (exclusion wins); dispute path `repo/src/refunds.js` is `blocked-disputed`; retired `send-v1.md` is `blocked-retired`.

- **Applicability:** every condition routed `legacy.ping` through `sendDirect`, matching `legacy.alert`. Methodrail answers named the exclusion. Capable baselines copied the local legacy path without applying `dispatchOnce`. Neutral is the honest outcome gap: the hidden driver does not require Methodrail.
- **Dispute:** Cursor Methodrail left `refunds.js` unchanged and named Stripe, Adyen, and the evidence gap. Cursor baselines implemented a refund (r2 picked Stripe). Codex Methodrail **read both notes**, then implemented a dual Stripe/Adyen dispatcher keyed on event fields instead of refusing. Codex baseline implemented a generic posted refund and named neither processor. Dual-fail → empirical `incomplete`, not `harmed`.
- **Retirement:** every condition used `enqueueMail` with template `password-reset` and did not call `sendMail` v1. Methodrail answers refused `send-v1.md`. Capable baselines copied the live welcome-queue path. Neutral.
- **Governance mutations:** no `.methodrail/` note or `PROJECT.md` rewrite in any scored overlay.
- **Freshness:** these copies are git-less; unknown freshness was expected. Cursor Methodrail runs recorded `git cat-file` / `git diff` against the stored SHA (exit 128).
- **Note reads:** Codex command logs show `.methodrail/knowledge/` reads. Cursor note reads are in answers, not always in `COMMANDS.json` (Read tool, `operator_summary`).

## Codex dispute investigation

Not a grader false positive. The Methodrail Codex run named both processors and the dispute, then **patched** `repo/src/refunds.js` to call `stripe.refunds.create` or `adyen.refund` depending on which reference was present. The frozen grader requires an unchanged production file. Baseline also patched, so compareScores returns `incomplete` (both fail), not `harmed`. The trial is preserved. Agents were not rerun.

## What the pilot actually shows

On these three tiny fixtures:

- **Applicability** did not create an outcome gap. Baselines already used `sendDirect` in the legacy sender.
- **Retirement** did not create an outcome gap. Baselines already copied `enqueueMail` from welcome.
- **Dispute** created an outcome gap on Cursor (refuse vs implement). Codex Methodrail recognized the dispute and still implemented.

Do not generalize beyond this n and these hosts. Cursor is the same product Grok as this session. Codex `--ignore-user-config` is the cleaner independent host.
