# Examples

## Investigate

`How does authentication work?` → investigate + how. Answer with entrypoints, flow, evidence, unknowns. Do not modify code.

## Develop

`Add organization-level billing` → develop, high rigor, how + domain-modeling + architect likely. Resolve frontier questions before a complete plan. Verify before complete.

## Debug

`CPU spikes after idle` → debug. Reproduce, how, hypotheses, observe, minimal fix, verify.

See evals under `evals/routing/` and `evals/pressure/` for the locked routing contracts.
