# Family integration

Use this checklist when adopting or modifying a Methodrail skill. Do not copy it into every `SKILL.md`.

```text
[ ] canonical capability owner
[ ] upstream fidelity reviewed
[ ] project knowledge integration considered
[ ] freshness considered
[ ] evidence vocabulary consistent
[ ] deterministic-tool opportunities considered
[ ] project verification integration considered
[ ] nearest-neighbor transitions clear
[ ] invocation proportional/conservative
[ ] context load reviewed
[ ] permanent context unchanged unless justified
[ ] family invariant unchanged unless a host projection was regenerated
[ ] behavioral eval
[ ] composition or fidelity eval when the change is about skill interaction or upstream behavior
[ ] pressure eval if discipline-enforcing
[ ] provenance updated
```

Share infrastructure aggressively. Compose procedures conservatively. Complexity must earn its keep.
