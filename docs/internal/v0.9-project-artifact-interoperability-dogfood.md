Scope: current v0.9 worktree churn under `src/`, not a whole-repository cleanup hunt. Committed history since v0.8.0 is eval/docs; the hot modules are uncommitted maintainer helpers. Vocabulary from `codebase-design`: module, interface, depth, seam. No source edits. No HTML. No typed-note write.

### Candidates

**`src/eval/grade-outcome.ts` — preserve.** Fixture graders behind `gradeOutcome(run, ctx)`. Deleting it would reappear as duplicated scoring in tests and `evals/runners/cli.ts`. High churn from four new graders is not a rewrite reason. Already a deep dispatch table. Verification: `npm run eval` and `tests/eval-v0.9-specifications.test.ts`. Strength: not a candidate.

**`src/artifacts.ts` — deepen — Worth exploring.** New maintainer discovery/preview module. Earns existence (tests and dogfood call `discoverProjectArtifacts`). Interface is still wide: classify, conflict, preview, and linked-harness walking live in one file; pointer matching is string `includes` of repo paths, which is why mixed PROJECT.md `knowledge/fees.md` hrefs still preview as `adopt`. Callers: v0.9 tests and this dogfood. Behavior to preserve: role taxonomy, conflict-not-guess, linked storage walk, bind-fail `unavailable`. Verification exists (`tests/v0.9-artifact-interoperability.test.ts`) but no characterization of pointer-href vs repo-path. Strength: Worth exploring. Not Strong (seam/verification for a split still uncertain).

**`src/project-md.ts` — preserve.** Small index-quality module; link decode and existence checks sit behind `evaluateProjectMdFile`. Quiet except this branch.

**`src/knowledge/report.ts` evidence-pointer warnings — preserve.** Incremental; deleting the helper would scatter link checks. Not a pass-through.

**Quiet speculative splits of `validate.ts` — reject.** No current-work evidence to split it.
