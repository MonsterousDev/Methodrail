# Adapters

Internal Methodrail files are authoritative. Adapters **project** them.

| Target | Projection |
| --- | --- |
| Cursor | Thin `alwaysApply` router rule, `METHODRAIL.md` catalog, per-skill `SKILL.md` |
| Claude Code | `CLAUDE.md` pointer + skill directories |
| Codex | `AGENTS.md` + skill directories |
| Generic | Agent Skills `SKILL.md` layout |

Limitations are documented in each generated `LIMITATIONS.md`. Feature gaps are not papered over.

Cursor does not get a second router. The always-on rule is short on purpose: progressive disclosure.
