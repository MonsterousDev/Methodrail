# Philosophy

Understand before changing.
Observe rather than assume.
Distinguish fact from inference.
Resolve uncertainty using the cheapest reliable source.
Turn decisions into bounded executable work.
Require evidence before claiming success.
Preserve only knowledge worth preserving.
Turn repeated lessons into structural constraints whenever possible.

Guiding questions while working:

- Is this a skill or a workflow?
- Is this knowledge or discoverable state?
- Is this evidence or a conclusion?
- Is this an agent judgment or a deterministic check?
- Should this live in permanent context?
- Could this be progressively disclosed?
- Could this failure be prevented structurally?
- Does this require human judgment?
- Can runtime evidence answer it instead?
- How will we know this skill actually helps?
- What happens when this knowledge becomes stale?
- What is the cheapest reliable way to establish truth?
