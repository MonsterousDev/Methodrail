# Control

Document only capabilities the repository actually provides. Do not invent start, doctor, or reset commands.

## Start

How the system is started using observed project commands.

## Doctor / readiness

What proves the system is ready for representative work.

## Drive

How to exercise a representative user/client path.

## Inspect

How to inspect runtime or persisted state.

## Capture

How to capture evidence (logs, traces, screenshots, artifacts).

## Reset

How to return an isolated environment to a known state.

## Stop

How to stop local processes started for this work.

## Known limitations

Environments, credentials, or capabilities that are unavailable or unsafe to invent.
